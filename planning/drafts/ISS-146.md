## Why

Chase Sets #7766 corrective run `m2-jpeg-corrective-20260914T1402` stopped in delivery at independently reviewed candidate `42bac8439e31b8354447f2675edfaea72890d4b5`. Reproduction of the full static chain found only `check:structure` failing on `bounded-contexts/marketplace/artifacts/jpeg-corrective`, two empty git-ignored directories created by the author inside the attempt-5 source worktree. They are absent from the commit and hosted CI; attempt 1 has the same scratch, explaining the earlier static stop. The 500-character stop diagnostic hid the actual failing subcheck. Learning note: https://github.com/chase-sets/chase-sets/issues/7766#issuecomment-5666590839. Todd's ruling: https://github.com/chase-sets/chase-sets/issues/4388#issuecomment-5666535088. This is a recurring loop defect, not a product finding.

## Done when

- Author scratch and evidence writes are confined to the existing attempt temp root (`author-temp`), outside the source tree. Apply the same existing-path rule on initial, corrective and resumed launches; do not add a separate authority framework.
- Delivery gates run against the committed candidate tree, or explicitly refuse source-tree contamination with the offending untracked/ignored path. An empty ignored scratch directory cannot become an unexplained committed-product failure. Preserve tracked edits and unrelated paths; do not silently clean the source worktree.
- Persist the complete failing command and diagnostic and expose its artifact path in the stop note and native recovery inputs. A 500-character excerpt is not the only retained evidence. Keep ordinary exact-head independent review and all local/hosted gates.
- Regress the observed empty ignored directory, clean committed tree, actual committed structure failure and nonempty contamination cases. Cover resumed delivery without minting another author, implementation attempt or corrective cycle; retain old runtime, reviews and consumed attempts unchanged.
- Document the small native behavior and its limits. This implementation supplies no permission to restart #7766 or to mutate its preserved worktree/runtime.

## Out of scope

JPEG product edits, host PR #8005 mutation or CI reruns, attempt-budget reset, new generic sandbox/receipt framework, deleting historical evidence, weakening structure validation, rollback or milestone ownership transfer. Todd separately authorized only a one-time removal of the two proven-empty ignored directories in attempt-5 source and unchanged-config resume of its existing delivery phase. A consumed-cycle refusal or any other gate failure requires a new rollback proposal and wait.
