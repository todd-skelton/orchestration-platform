## Scope fence

In scope: the bundled WSL Node artifact identity, its verified acquisition/installation receipt, the executor shell/PowerShell/status pins, and focused executor tests/fixtures. The product engine range is the source of truth. Use Node `v24.16.0`, the smallest release satisfying `>=24.16.0 <25`; obtain the official `node-v24.16.0-linux-x64.tar.xz` and its matching upstream `SHASUMS256.txt`, verify the archive hash before unpacking, and install it under the executor tools root as `tools/node-v24.16.0-linux-x64/bin/node`. The checked-in scripts must use that exact path; no runtime download, PATH fallback, or literal-model/provider change is allowed.

Non-goals: changing `docs/loop.md` semantics, quiescent lock/restart behavior, gate timeouts, verifier admission, reservations, attempts, charges, parking, retries, review authority, product code, product timeout tests, hosted CI policy, Windows runner images, or any TCGplayer integration. Heavy reproduction and ControllerBattery/ControllerPrecursor are not part of this lane.
