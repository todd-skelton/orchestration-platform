## Git semantics verified for r2

Git `2.55.0.windows.5`, 2026-10-20, disposable repositories under this
worktree's ignored `.artifacts/iss259-r2/`; no network/live-runtime writes:

- `git rev-parse --show-toplevel HEAD` matched separate
  `git rev-parse --show-toplevel` and `git rev-parse HEAD`, in that order.
- `git status --porcelain=v2 --branch` matched separate HEAD, current
  branch (`git branch --show-current`) and clean/dirty
  (`git status --porcelain`). Clean means no non-header entries;
  map `(detached)` to empty branch. Both passed on main, untracked, staged,
  staged+unstaged, detached, nested-directory and linked-worktree cases.
- Unborn HEAD: combined rev-parse exits 128; v2 OID is `(initial)`.
  On command failure or missing/invalid facts, fall back to original reads
  to preserve earlier root/revision refusals, including multi-fault cases.
- With `remote.origin.url=fixture:owner/repo.git`,
  `url.https://github.com/.insteadOf=fixture:` and
  `url.ssh://git@push.example/.pushInsteadOf=fixture:`,
  `git remote get-url --all origin` returned HTTPS fetch,
  `git remote get-url --push --all origin` SSH push;
  `git ls-remote --get-url origin` only fetch: rejected.
- After `git config --add remote.origin.url fixture:other/repo.git`,
  `get-url --all` returned two fetch URLs but `git remote -v` one fetch row.
  Reject `remote -v` despite push rewriting. Reject raw
  `git config --get-regexp '^(remote\.origin\.(url|pushurl)|url\..*\.(insteadof|pushinsteadof))$'`
  alone: raw aliases, not effective URLs. No new rewrite resolver.
- With `extensions.worktreeConfig=true`, linked-worktree
  `git config --worktree remote.origin.pushurl fixture:push/repo.git`
  made `get-url --push --all origin` return
  `https://github.com/push/repo.git`: pushurl uses insteadOf, suppresses
  pushInsteadOf, differs from root. Keep fresh fetch/push reads per root.
