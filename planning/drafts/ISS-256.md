The smallest alternative is wrapping the native repair call in the existing delivery `finalStep`, but attempt 5's own draft regression reached `unreviewed-delivery-source` that way, so it is not assumed safe.
Choose regression-first delivery: first the repair-role production regressions and one-variable negatives that fail on ISS-255's landed code for the owning reason, then the smallest queue change that turns them green with the delivery guard unchanged.
Accept that the routing seam is chosen by the failing regressions rather than fixed in advance, and that the retained attempt-5 diff may be discarded entirely.
Revisit if green requires weakening `unreviewed-delivery-source`, allocating an implementation attempt during planning, or a production change outside the declared footprint.
