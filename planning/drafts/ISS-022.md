## Question

Can Node.js 24 alone prove the required atomic replace, create-once,
compare-and-swap, lock isolation, native argument launch, process-tree identity,
and bounded termination guarantees on current macOS, Windows, and Linux?

## Probe method and lifecycle timing

Run the stable cross-platform harness from `ISS-006` in clean hosted runners.
Exercise controlled concurrent writers, crash points, inherited handles,
argument canaries, parent/child/sibling processes, and termination timeouts at
the exact mutation and process-lifecycle boundaries consumed by `ISS-004` and
`ISS-005`.

## Required durable evidence

Publish one capability matrix per exact OS image and Node version, raw but
scrubbed command outcomes, normalized receipts, and negative controls. Bind all
artifacts to the probe source/test-bundle digest.

## Disposition rule

- If every required guarantee is proven with Node APIs, `ISS-004` and `ISS-005`
  remain Node-only.
- If a guarantee is unsupported but a bounded native-helper protocol can prove
  it on all targets, file one fixed-scope helper slice and block the affected
  implementation on it.
- If any guarantee cannot be proven on a required OS, return `BLOCK_REPLAN` and
  do not weaken or silently skip that guarantee.

## Scope fence

Out: implementing production primitives, choosing project policy, or treating a
successful result on one OS as evidence for another.

## Verification plan

`pnpm run probe:portable-primitives`

`pnpm run probe:portable-primitives:verify-receipts`

## Predicted footprint and dependencies

Owns `probes/portable-primitives/` and capability receipts. Blocked by contracts
and the early trusted OS harness; blocks state and process implementation.

## Operator actions

None beyond access to standard hosted runners.

## Independent review packet seed

Attack runner-image ambiguity, probes that test success but not isolation,
inherited-handle blind spots, shell-mediated launch, missing crash boundaries,
and unsupported results normalized to pass. Use the complete capability matrix.
