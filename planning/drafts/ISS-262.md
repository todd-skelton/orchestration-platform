`synthetic`, `launchId`, `role` (`author|repair|reviewer`), positive `issue`,
`run`, positive `attempt`, absolute `tracePath`, `terminalPath`, `stopPath`,
`observedAt`, `probeStartedAt`, `poolAt`, `catalogAt`, `requestAt`, `traceAt`,
`terminalAt`, `stopAt`, `probeFinishedAt`, `evidence[]`, `disposition`.
Every evidence item is exactly
`kind` (`pool|catalog|request|trace|stderr|terminal|stop`), absolute `path`,
raw-byte `sha256` (64 lowercase hex), and `capturedAt`. Timestamps are
timezone-bearing instants in this order:
`probeStartedAt <= poolAt <= catalogAt <= requestAt <= traceAt <= terminalAt <= stopAt <= probeFinishedAt`.
`synthetic` is true for the probe and `launchId` starts
`synthetic-iss262-`; all artifacts carry that same identity. Unknown fields,
duplicate kinds, missing paths/digests, bad ordering, non-ASCII-safe paths,
or binding mismatch are non-authority: retain existing evidence, refuse before
reservation, and infer no category.
