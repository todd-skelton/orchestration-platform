## Decision

Add one bounded causal-attribution layer to the existing launch/observe path.
The worker adapter must retain safe categories and evidence references for
model-catalog/model-manager refresh timeout, tool-schema/argument parse failure,
provider/account refusal, and a candidate semantic verdict. The supervisor and
saved-stop reader must consume that structured result before projecting
`launcher-failed`; no raw stderr, credentials, or free-form worker prose is a
new authority. Existing retry/parking behavior remains unchanged unless a
separately reviewed fault-class table entry explicitly preserves the current
non-parking/parking contract.

The smallest acceptable shape is a shared bounded classifier plus additive
retained evidence at the current adapter/flow/supervision seams. Do not build a
second launcher, catalog probe, provider router, retry engine, process census,
ControllerBattery, or ControllerPrecursor path.

   model-catalog/model-manager refresh timeout, tool-schema/argument parse
