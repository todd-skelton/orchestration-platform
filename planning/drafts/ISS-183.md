## Decision

Constraint: recover transport failure without accepting rejected work, losing
partial edits or renewing any budget. Simplest alternative: repeat the existing
JSON-only prompt, already insufficient here. Chosen: extend the existing native
malformed-terminal/retry path to authors, with bounded diagnostics and the
existing attempt/retry/history records. For this completed malformed author,
retry against the same base and retained partial work, not the dead-author
clean-base reset. The new worker inspects the trace and work and returns its own
valid verdict; the host never truncates or synthesizes one. Accepted downside:
one more charged native launch, and a small role-specific distinction from dead
worker cleanup. Revisit only on a recorded failure this bounded path cannot
represent; do not create a general recovery framework or fresh receipt protocol.
