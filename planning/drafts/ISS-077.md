## Scope and observed evidence

Correct the private delivery adapter's local branch observation so successful
exact absence is distinct from a failed, malformed, ambiguous, or prefix lookup.
Exercise that lookup through real Git-backed cleanup and restart behavior; keep
the existing cleanup authority, exact head checks, collision behavior, remote
target verification, and receipt transitions unchanged.

## G0 and smallest complete shape

G0: PASS. The smallest complete shape is one bounded private local-ref query
correction in `delivery-adapter.ts` and focused real-adapter coverage in its
existing test file. The query must complete successfully, return the exact
requested ref with a well-formed object name, or return no rows for confirmed
absence. Failed commands, malformed rows, prefix rows and multiple rows remain
unknown through `observeCleanup`.

Not built: generic Git abstraction; setup-adapter refactor; new public contract;
retry, fallback or arbitrary cleanup adoption; queue or existing-PR refresh;
provider, credential, environment or mutation-authority changes; package,
compiler or public-capability changes; production promotion; operational proof
from source or fixtures. Each is either unrelated to the observed lookup defect
or would widen authority beyond the five criteria.

   rather than mocking the faulty lookup away. Keep all previous assertions and
   exact-source review evidence.

   restart with its own reviewed adapter. Until that operational proof exists,
   ISS-074's real-use obligation remains open. No synthetic failure is
   manufactured merely to exercise repair automation.
