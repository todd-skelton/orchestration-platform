## Decision

Saved selections must keep one immutable brief and base, with all prior accounting intact.
An explicit zero-attempt re-pin is possible but would add a new persisted transition and authority boundary to solve this one recovery.
Choose documentation-only guidance for the existing host-authorized fresh-run route, restricted to an entirely unattempted run and issue lineage.
Accept a manual recovery and a new run name rather than claim same-run or unattended recovery.
The choice is wrong if a recorded eligible recovery cannot use that route without changing old state or renewing a consumed allowance.
