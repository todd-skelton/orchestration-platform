## Why

The M2 run m2-payout-fees-replanned-20260913 delivered Seller Payout Fees
issue #7821 through native author/review, PR #7973, queue merge a9d697bd,
and verified staging/production deployment run34767773892. Its next selection
was #4382 from Founder TCGplayer Operated Pilot (milestone148), while the
supervised Seller Payout Fees milestone155 still had #7820 needs-operator.

The product pull window advances to runnable work in later outcomes, and the
loop config has no explicit selected-milestone limit. The host stopped
supervisor573818 and new author610986 before its clean source checkout changed.
This run was authorized to deliver the selected M2 milestone, not take over
routine later-outcome delivery. Saved cycle2 selection and interrupted worker
remain preserved. This is the concrete boundary crossing being removed.

## Done when

- A Chase Sets supervision config can name its target milestone using a stable
  repository milestone identity. The original M2 run can be scoped to155 without
  mutating historical worker/review/merge/deploy evidence or resetting attempts.
- Fresh selection and saved-selection resume honor the explicit scope before
  author dispatch. A saved out-of-scope selection stops with an actionable host
  reason; it is not parked, reauthored, or silently relabeled complete.
- When the selected milestone has no runnable issue, the run reaches idle or an
  appropriate typed stop without following later product outcomes. This is not
  a claim that operator-blocked admitted scope or the milestone itself is complete.
- Current product readiness, native dependencies and issue exclusions remain in
  force. Unscoped self behavior and general Chase Sets behavior remain compatible.
- Composed tests reproduce milestone155 exhausted/operator-blocked plus runnable
  milestone148, and saved cycle2 #4382, proving no out-of-scope author launch.
  The intended target still selects runnable issues and honors their dependencies.
- Document the small config option and concrete preserved-run recovery. Preserve
  the interrupted #4382 attempt and completed #7821 records; no fake worker PASS,
  unreviewed runtime edits, new generic migration framework, or attempt-budget reset.

## Out of scope

Changing product outcome priority, scope or labels; implementing #4382; replacing
native product readiness; completing operator approvals; broad scheduler rewrites.
