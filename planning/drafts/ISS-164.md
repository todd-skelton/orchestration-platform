Not the author's work and not an acceptance prerequisite for the author's PASS. Separately, on the Windows incumbent host, in the ROOT container with `PlatformWorktree`/`PlatformBranch`/`PlatformHead` a clean attached target and `Lane` a valid label, the host may run the incumbent gate under its own existing machine admission:

```powershell

```

Branch mode only, no ImmutableHead; missing branch, wrong head, dirty target or mixed identity refuse before the body. Native is future API; `-Gate` binds the current wrapper. The machine-admission rule governs that Windows ROOT container only; it places no requirement on the platform author's Linux worktree.
