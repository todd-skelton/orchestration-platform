### Discriminator alternatives and limits

Running gates on the marker tree is rejected: the merge explicitly requests
markers at `scripts/dogfood/conflict.ts:52-57`, and unmarked
`test/dogfood/queue.test.ts:36` imports a marked module in the real incident.
Failure location is not causal attribution.

Alternative (a), an isolated `-X ours` projection, removes those syntax errors
but tests a guessed resolution, not the author's result. A red projection may
be repaired entirely inside marked hunks; a green one may discard required
main behavior. Neither result proves reachability. In ISS-146 it might expose
the cwd/log assertions, but the supplied evidence contains no such executed
projection. It also needs isolated gate execution and arbitrary-output
attribution that the current author prompt does not provide.

Choose alternative (b): a marker-independent, deliberately conservative
**unsupported combination** policy, not a semantic-futility detector. At the
pinned marker seed, refuse when a regular text file outside the captured set
has a blob different from both parents at that exact path. This is a concrete
immutable two-parent combination the hunk-only author cannot edit. AC1 defines
the complete predicate; it does not infer bugs from filenames or diagnostics.

False positives relative to semantic viability are intentional: two harmless,
disjoint edits can combine successfully yet meet this predicate and be parked.
False negatives are also possible: a file identical to one parent can fail
because another file changed; marked files can contain immutable bad text
outside their hunks; excluded file kinds and clean integrations are not covered.
An empty result means only "no unsupported combination under this policy",
never "preservation is possible" or gate PASS. The narrower rule avoids F1's
systematic marker/importer false stop, not every possible false stop.

ISS-146's reported auto-merges motivate the policy but do not establish the
three blob inequalities. This lane did not recreate its retained merge, and
does not claim this rule would certainly have prevented cycle 10. A synthetic
ISS-146-shaped fixture proves the bounded rule, not that historical claim.
No implementation worker should invent a stronger historical assertion or
silently broaden the predicate to catch it.

## Decision

The hunk-only continuation cannot edit unmarked combinations, and gate failure locations cannot prove which edits preservation requires. The simplest alternative is to retain today's author-driven discovery with no new preflight. Choose a read-only three-tree blob comparison and a durable item-scoped refusal before the conflict author, only for integration continuations. Accept conservative parks of viable two-parent combinations and missed incompatibilities outside the explicit predicate rather than claiming a sound and complete futility test. Evidence that these deliberate false parks cost more than the saved launches would invalidate this policy and require a separate planning decision, not automatic scope widening or a new attempt.
