## Done when

- **AC1: Literal matching.** `withinConflictHunks(before, after)` keeps its boolean
  API and Git hunk grammar; no source-derived regex or placement backtracking.
  Fixed prefix and suffix remain anchored to the exact start/end; intervening
  fixed segments stay ordered, non-overlapping, without suffix-byte reuse.
  Fixed LF/CRLF, whitespace and metacharacters remain literal/immutable.
  Evidence: exported-function tables in `refresh.test.ts`: repeated fixed
  segments and suffix text inside a resolution.
- **AC2: Preserve acceptance and refusal.** One or multiple hunks, empty
  resolutions, adjacent hunks, empty prefix/suffix, and a whole-file hunk are
  accepted when valid. No recognized hunk or retained recognized markers means
  false. Negatives change only prefix, suffix, a middle fixed segment, segment
  order, or outside-hunk line endings. Mutate inside the fixed suffix, not beside
  the hunk boundary. Include
  leading extra text before the unchanged prefix and trailing extra text after
  the suffix, for LF/CRLF with all other input unchanged,
  and overlapping/reused fixed-segment placement. Evidence: single-variable
  table pairs; retain
  `limits edits to actual hunks with line ending %j` tests.
- **AC3: Regress the real failure and scale.** Replay the exact retained input
  read-only: candidate accepts the host's empty-hunk resolution without throwing
  and rejects a one-byte fixed-text change. Record hash, exact candidate head,
  command and output externally; commit no copy of `queue.ts`. Add deterministic
  synthetic controls: one hunk with a single contiguous 128 KiB fixed segment;
  many-hunk 1 MiB scale/scan control (NOT old-failure evidence). Include
  metacharacters, repeated near-matches and late missing
  suffix/segment. Evidence: large-single-fixed-segment control makes old matcher
  throw `SyntaxError` / `Regular expression too large`, repaired matcher return

  Pass under existing timeouts; record measured sizes/timings and monotone scan
  bound. No benchmark framework, timeout increase or size cap.

  binary, missing-side and unsupported-mode conflicts retain

  Evidence: extend the local-Git refresh fixture with large-file,
  unsupported/scope controls. Existing fresh/resumed,

  green: one resolution allowance, original records/participants, exact-head
