## Scope fence

In scope: the default author verification text in
`scripts/dogfood/flow.ts` and its focused `test/dogfood/flow.test.ts`
regression. The protocol applies to every verification command the author
starts under the default gates, including the full suite and focused Vitest
runs: wait for terminal exit, send no input or Ctrl-C merely because output is
quiet, record the observed exit code, and report FAIL when completion evidence
is absent. For the silent full `pnpm test` (which may run about 45-50 minutes),
write stdout and stderr outside the worktree in the author temporary directory:
POSIX shells use `pnpm test > "$TMPDIR/pnpm-test.log" 2>&1; echo "exit=$?"`,
and PowerShell uses `pnpm test *> "$env:TEMP\pnpm-test.log"; "exit=$LASTEXITCODE"`.
The source and test literals must preserve the separator before
`pnpm-test.log` (escape the backslash as `\\` in a JavaScript string, or use
`/`). "Bounded" means reading back at most the last 40 lines plus the exit
code, never pasting raw log output into the final summary, and not rerunning a
command that already completed on an unchanged worktree merely to see its
output again (read the retained log tail instead); after a source change,
rerun the affected checks as the existing "fix what fails" rule requires, and
report PASS only from the latest completed run of each required gate on the
final worktree. Waiting means continued empty polls or long yields until the
process exits; an empty poll is not input. Host-lane heavy-command
refusal is governed by the host heavy-verification contract outside this
repository and is not proven by `flow.test.ts`.

Keep the recurring instruction compact: every fully assembled corrective
author prompt, including inherited evidence and retry context, must remain
strictly below 8000 characters (`String.length`), not merely the new text or
the direct `workerPrompt` return. Preserve the existing cap and assertions;
do not truncate evidence, drop protocol clauses, or add shell probes to the
recurring instruction. Main-head measurements for the existing corrective
fixture are 7045/7706/7062/7112 characters (initial/legacy retry/corrected/
corrected-refreshed), leaving at most 293 additional characters in its tightest
case. These are fixture measurements, not a universal headroom guarantee.
If the complete compact instruction cannot fit, return the shortest complete
wording and measured composed prompts to the host for an explicit cap decision
with rationale, evidence and reversal condition, flagged for independent
review; this repair does not authorize a cap increase.

Non-goals: no worker timeout, turn ceiling, retry, reservation, attempt or
