## Why

`docs/loop.md` is "the only process document" and the self adapter injects
all of it into every author and reviewer prompt (`adapters/self.mjs`
`issueContext`, `queue.ts` `promptContext`). Measured non-empty lines:
69 on 2026-09-10 (`430c604`), 101 on 09-12 (`a2614c0`), 532 on 09-14
(`e23165a`), 726 at `6f4175b` on 09-16. The nine rules occupy about
thirty of them; 21 paragraphs beginning `ISS-NNN records` hold the rest.
Those paragraphs are not disposable: many state current behavior (ISS-158
ladders, ISS-166 handoff, ISS-162 admission) that no rule sentence repeats.
Moving them wholesale would remove worker guidance; leaving them buries the
rules under history. `planning/evidence/ISS-134-recovery.md` already shows
the intended home for narrative.

## Decision

Constraint: no standing behavior described today may disappear from what
workers read, and rule 9's authority model is unchanged. Simplest
alternative: a line cap on the document, which invites deletion by
compression. Chosen: for each incident paragraph, keep its standing contract
as a sentence in the Rules, Planning or Running section it governs, and move
the incident narrative, hashes, PR numbers and run names to
`planning/evidence/<ISS-key>.md`. Accepted downside: a reviewer must read
each paragraph twice, once in each home. Revisit when: a worker stop or
review finding cites behavior that was only in a moved paragraph.

## Done when

- `docs/loop.md` contains no paragraph beginning `ISS-NNN records`. Each
  such paragraph at `6f4175b` is either restated as one or more sentences in
  the section that governs it, with the issue key in parentheses, or is
  already covered by an existing rule; the PR description lists all 21
  paragraphs with the sentence or rule that now carries each one.
- The narrative of each moved paragraph (run names, commit hashes, PR and
  comment numbers, what was observed, what was rejected and why) lives in
  `planning/evidence/<ISS-key>.md`, one file per incident, verbatim except
  for a title line. Nothing recorded at `6f4175b` is lost.
- Rules, Planning, Running, Milestones and Not carried forward keep their
  headings and order; `adapters/self.mjs` and every prompt composition site
  are unchanged. The document is not renamed or split into multiple process
  documents.
- Tests that read `docs/loop.md` still pass unchanged; run typecheck,
  format:check, planning:check and test. The independent reviewer confirms
  the 21-row mapping against the two homes, not only the diff.

## Out of scope

document, editing runtime records, or moving the Planning and Running
reference material (routing rows, draft grammar, executor paths).
