## Context and evidence

Decision #302's readiness audit (§4, F1) found that `PROTECTION_RUN_ID`,
`PROTECTION_ARTIFACT_ID`, `PROTECTION_RECEIPT_SHA256`, and
`PROTECTION_ARTIFACT_ARCHIVE_SHA256` — `ISS-036`'s sole post-upload output and
`ISS-038`'s sole admission path for it
(`planning/drafts/ISS-038.md`'s acceptance criterion 9) — have no schema,
parser, grammar, digest domain, or vector anywhere in the repository. The
receipt's `environmentBinding` closes at exactly `environmentEtag`,
`environmentName`, `variableName`, `variableUpdatedAt`, and `variableValue`,
naming only the two literals `host-custody-bootstrap-root` and
`VERIFIER_ANCHOR_SHA256` (`contract-decisions.md:6978-6981`); the receipt
deliberately excludes post-upload identity because those values do not exist
until after the receipt bytes are uploaded (`:6974-6977`). Decision #302's
ruling 2A requires this issue to get its own Decision before any authoring.

## Scope fence

In: close finding F1. Write the ledger clause with the same rigor as
`docs/architecture/contract-decisions.md:6639-7206`, and, if the Decision so
rules, the closed parser/vector family for the four values — most likely as
an ISS-054-shaped contract slice, not inside `ISS-036`.

Out: producing or consuming the four values. This issue defines the contract;
`ISS-036` (producer, live) and `ISS-038` (consumer) remain the only issues
that touch a live value.

## Gating

This is a closed-ledger amendment and therefore needs its own `Decision:`
before authoring, per Decision #302 ruling 2A, filed by the controller host
once CF-0 (this planning repair) lands. It blocks `ISS-036`'s live sub-slices
L5 and L6 (the producer window and the post-upload variable read-back), not
the credential-free sub-slices `ISS-056`..`ISS-062`.

## Acceptance criteria and evidence

1. A ledger clause naming the four values' grammar, digest domain (if any),
   and the exact transport that carries them from `ISS-036`'s producer window
   to `ISS-038`'s consumption, with the same rigor as the existing
   `environmentBinding` clause.
2. If the ruling chooses a closed parser/vector family, parser and vectors at
   the same standard as the Packet B twelve, including a refusal for a fifth
   admitted environment variable (the receipt's `environmentBinding` has
   exactly five members and names exactly two literals —
   `contract-decisions.md:6978-6981` — so these four values cannot be folded
   into it and must define a separate transport).
3. `ISS-038`'s acceptance criterion 9 and `ISS-036`'s acceptance criterion 7
   both resolve against this issue's grammar without further amendment.
