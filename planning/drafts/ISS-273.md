## Scope fence

In scope: the stop-record schema and writers/readers for local-gate diagnostics, the supervisor blocked-line projection, and focused regression fixtures over 64 KiB. Prefer a digest-bound complete artifact reference: retain the existing `candidate.log`/`gate-stop.json` (or a dedicated adjacent diagnostic artifact when the source is not otherwise retained), and write only bounded metadata into `gate-stop.json`/the supervisor line: artifact path, exact byte length, SHA-256, gate, command identity, candidate head and terminal path. Readers must resolve the named artifact, verify length and digest, and expose bounded slices only for display.

Non-goals: increasing display limits, embedding complete logs in supervisor stdout, changing the native DB 65,536/8,192-byte protocol, changing gate attribution rules, adding a second stop/retry path, altering attempts/charges/reservations/parking/review authority, changing product tests/timeouts, executor Node version, hosted CI, or any TCGplayer integration.

## Simplest shape

One shared complete-artifact reference/verification helper used by the local-gate stop writer and supervisor projection, plus a focused >64-KiB regression. Delete the raw diagnostic truncation path; do not add a larger inline cap.

## Defect-class constraints

- `presence-evidence-treated-as-completeness` and `canonical-artifact-directory-masks-missing-payload`: require readable bytes, exact length and digest; directory presence or a truncated preview is never completeness.
- `retained-artifact-schema-ratchet`: old stop/gate records remain readable; new metadata is additive and no historical bytes are rewritten.
- `closed-schema-shallow-validation`: close and validate nested reference metadata, path normalization, digest shape, byte length, gate/head/command identity and terminal binding.
- `temporal-join-ignores-causality`: bind artifact, gate, command, candidate head, terminal and stop occurrence; a later artifact cannot authorize an earlier stop.
- `missing-fail-closed-regression-evidence`: freeze the >64-KiB fixture and require baseline-red/candidate-green plus slice-restoration, deleted-artifact and digest-mismatch mutants-red.
- `unrunnable-verification-command`: focused tests resolve against the trusted manifest and intended shell; heavy reproduction returns to the host.
- `vitest-wall-clock-timeout-under-parallel-host-load`: silence is not timeout proof; preserve first results and do not weaken test limits or run parallel heavy verifiers.
- `future-capability-documented-as-current`: documentation names the artifact-reference contract only after the exact-head implementation and review pass.
