## Context and evidence

Round 476 records the observed need: the native child-environment filter omitted
the five delivery-credential names. Controller launch containment removed them
for this run; this small additive repair makes that exclusion automatic for
future native worker launches without claiming full credential isolation.

## Scope and non-goals

In: exclude `GH_TOKEN`, `GITHUB_TOKEN`, `GITHUB_PERSONAL_ACCESS_TOKEN`,
`GH_ENTERPRISE_TOKEN`, and `GITHUB_ENTERPRISE_TOKEN` case-insensitively from
the copied child environment; cover exact names and case aliases with synthetic
fixtures; preserve the parent, unrelated values, and native provider auth/home.

Out: broker changes, credential rotation, provider mutation, sandbox changes,
environment serialization, full credential isolation, publication, promotion,
or activation.

## Acceptance criteria and evidence

1. The five exact names and case aliases are absent from the fake child while
   native provider auth/home and unrelated synthetic values remain available.
2. The parent environment remains byte-for-byte equivalent to its pre-filter
   synthetic object.
3. The fixture checks only definedness; no environment value is enumerated,
   printed, recorded, or used as a receipt.

## Verification plan

Source attempt 1 runs only direct installed TypeScript, pinned Prettier over
changed executable paths, and the planning check. It does not run local tests,
native builds, probes, lock experiments, candidate activation, or package gates.
Independent review attempt 2 attacks the isolated exact source head; the
controller retains board mirroring, four actual package gates, and publication
authority.

## Predicted footprint and review attack surface

Predicted full change: the adapter, focused adapter test and provider fixture,
the concise supervised-dogfood note, this draft, the kernel epic, one M2 roadmap
row, and round 476. Attack case-insensitive bypasses, child leakage, parent
mutation, loss of provider auth/home or unrelated values, secret output, and
claims of broader isolation or authority.

## Falsifiable prediction

The next ordinary cycle's native worker child lacks all five named delivery
credential variables while preserving unrelated values and provider auth/home.
Any named variable or case alias reaching that child, or a required preserved
value disappearing, falsifies this bounded repair and requires replanning from
new evidence.
