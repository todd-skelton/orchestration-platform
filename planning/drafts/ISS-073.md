## Scope and non-goals

In: build each child environment from an empty object at controller-to-observer
and observer-to-native-worker. Copy only `PATH`, `PATHEXT`, `SYSTEMROOT`,
`WINDIR`, `COMSPEC`, `TEMP`, `TMP`, `TMPDIR`, `CODEX_HOME`, `HOME`,
`USERPROFILE`, `HOMEDRIVE`, `HOMEPATH`, `APPDATA`, `LOCALAPPDATA`,
`XDG_CONFIG_HOME`, and `XDG_DATA_HOME`. POSIX matches only these exact uppercase
names. Windows matches case-insensitively, emits canonical uppercase names and
prefers an exact canonical entry. Preserve exact required-location values and
the unchanged parent; omit every unknown name without logging it.

Windows additionally permits only `LOGONSERVER`, `SYSTEMDRIVE`, `USERDOMAIN`, and
`USERNAME`, which libuv otherwise supplies implicitly. Suppress Node's automatic
`NODE_V8_COVERAGE` inheritance with an own non-enumerable undefined property that
is not transported. Freeze the empty-prototype projection so unexpected later
JavaScript runtime additions refuse before spawn. On macOS, distinguish only
CoreFoundation's exact post-exec `__CF_USER_TEXT_ENCODING` metadata name in
synthetic fixture observations; never copy that name from the parent.

Out: broker, scheduler or public-contract expansion; arbitrary environment
overrides; credential rotation/invalidation; provider, sandbox or controller
environment mutation; filesystem/keychain isolation; network testing;
publication, promotion or activation.

## Acceptance criteria and evidence

1. Both production spawns have explicit environments produced from the empty
   allowlist builder; hosted fixtures fail either hop independently and inspect
   the actual observer and worker child environments.
2. Synthetic exact names, aliases, known delivery/cloud variables, proxies,
   `NODE_OPTIONS`, askpass, agent socket and arbitrary secrets are absent.
   Exact provider-auth location values and required startup-name presence remain.
3. POSIX exact-case and Windows case-insensitive/canonical behavior are asserted,
   parent objects remain equal to their snapshots, and fixture output contains
   no environment values. Direct-Node TypeScript import coverage remains.
4. Hosted process tests seed synthetic coverage paths outside the checkout and
   require coverage and its case aliases to be absent at both hops. Fixed boolean
   reports distinguish required-location preservation, forbidden-name absence,
   and the single macOS runtime addition; all other unknown names still fail.

## Falsifiable prediction

Each spawn receives only canonical allowlist values, without ambient coverage,
while its parent is unchanged. Actual child observations preserve exact required
locations and admit only the documented macOS runtime-generated metadata name
beyond the list. Parent propagation of an unknown name, any other child name,
a missing explicit environment, changed required value or platform case mismatch
falsifies this bounded repair.
