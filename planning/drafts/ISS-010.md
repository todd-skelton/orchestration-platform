## Context and evidence

Controller state must survive host rotation and be reconstructible without chat
history. See the event contracts from `ISS-002` and session model from `ISS-007`.

## Scope fence

In: append-only event writer, canonical event vocabulary, bounded readers,
deterministic reducers, snapshots, telemetry health, redaction, and replay.

Out: analytics dashboards, cost-provider integration, project board writes, and
automatic policy changes.

## Decisions already made

Authority events are strict and fail closed. Advisory telemetry may be null or
degraded but must say why. Reducers never rewrite history. Snapshot behavior
follows the `Journal and snapshot` state table.

## Acceptance criteria and evidence

1. Equivalent event histories reduce byte-identically on all target systems.
   Evidence: golden replay hashes.
2. Partial append, duplicate event, malformed row, and scan truncation have
   explicit non-success outcomes. Evidence: adversarial history fixtures.
3. Secrets and host-local paths are redacted before durable append. Evidence:
   seeded canary tests.
4. Snapshot restart reproduces a full replay result and detects a mismatched
   prefix. Evidence: snapshot equivalence and corruption tests.
5. `@orchestration-platform/journal` replaces only the static `journal`
   command-family placeholder. Evidence: registry census and append/reduce/
   snapshot command-envelope tests.

## Verification plan

`pnpm --filter @orchestration-platform/journal test`

`pnpm run test:replay-determinism`

## Predicted footprint and dependencies

Create implementation in predeclared `packages/journal/`, its static CLI
handler registration, replay fixtures, and snapshot contracts. Blocked by
`ISS-002`, `ISS-003`, `ISS-004`, and `ISS-007`; parallel
with `ISS-009` after shared dependencies. No shared-manifest or glossary edit.

## Independent review packet seed

Attack locale/timezone ordering, newline and encoding drift, partial terminal
rows, replay from a false prefix, redaction after serialization, and advisory
failure blocking authority. Use cross-OS golden histories plus corruption
mutants.
