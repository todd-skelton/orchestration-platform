## Context and evidence

Real self-hosting requires a concrete worker host, not only a provider-neutral
interface. The selected first host is the exact Codex CLI contract proven by
`ISS-023` and recorded in the contract decisions.

## Scope fence

In: CLI discovery, exact executable and version identity, exact requested and
reported model identity, native launch, role-specific prompts and credentials,
transcript/artifact binding, startup liveness, terminal receipt, and independent
review attempt isolation.

Out: other providers, remote workers, model-quality calibration, automatic
credential installation, or vendor-specific behavior in the core engine.

## Decisions already made

The adapter is an optional integration package and implements only the exact
minimum version, invocation, event, identity, and isolation contract admitted
by `ISS-023`. Aliases never satisfy exact identity.

## Acceptance criteria and evidence

1. Dispatch binds executable hash/path identity, CLI version, requested model,
   reported model, role, launch identity, and subject revision. Evidence:
   terminal worker-host receipt.
2. Missing CLI, version mismatch, model mismatch, alias-only identity, startup
   silence, or moved subject yields a named refusal without ownership leakage.
   Evidence: lifecycle mutation matrix.
3. Review attempts cannot access implementation mutation credentials and cannot
   reuse author attempt identity. Evidence: credential canaries and negative
   attempt tests.
4. The adapter passes the same host contract on macOS, Windows, and Linux when
   the CLI is available and emits capability refusal otherwise. Evidence:
   three-OS probe receipts.
5. Missing, malformed, or unknown worker role refuses before Codex launch; only
   explicit implementation attempts receive mutation-scoped credentials.
   Evidence: role omission and credential-canary matrix.
6. Per-attempt temporary homes and artifacts remain owned through forced
   launcher termination/restart and are reclaimed only after the exact process
   tree exits. Evidence: host-resource lifecycle and orphan negative tests.
7. `./bootstrap-canaries` exports only the typed
   `codex.authenticated-preflight/v1` descriptor and broker-side implementation
   from the broker-operation manifest. Its broker-injected role home runs the
   pinned authenticated preflight without
   dispatching work or emitting auth bytes. Evidence: static export/descriptor/
   implementation digest census and secret/output/moved-CLI canaries.
8. The installed adapter reruns the exact `ISS-023` filesystem and direct
   native-store extraction matrix for implementation, review, and observer
   roles on all three OSes. A successful `CredReadW`, `SecItemCopyMatching`,
   Secret Service, other-role-home, broker-endpoint, or process-memory read
   refuses certification; omission or incidental backend failure is not denial.

## Verification plan

`pnpm --filter @orchestration-platform/host-codex test`

`pnpm run host:codex:probe`

## Predicted footprint and dependencies

Fill only implementation/test files in the predeclared
`packages/host-codex/` skeleton; `ISS-000` owns its manifest and empty public
entrypoint and predeclared `./bootstrap-canaries` descriptor. Add scrubbed lifecycle fixtures. Blocked by process, dispatch,
modules, routing, adapter contracts, `ISS-023`, and `ISS-032`. Serial before bootstrap
certification.

## Operator actions

Install/authenticate the Codex CLI on designated test runners and approve a
bounded live probe. Credentials must not be committed or included in receipts.

## External authority probe and evidence timing

Capture CLI/executable identity immediately before launch and reported model
identity during startup before accepting worker liveness.

## Glossary impact

None; worker host and exact model identity are registered already.

## Independent review packet seed

Attack executable substitution, alias acceptance, reported/requested mismatch,
credential crossover, shell launch, stale subject, transcript confusion, and a
CLI absent on one OS being counted as pass. Use the lifecycle/identity matrix
and credential canary report.
