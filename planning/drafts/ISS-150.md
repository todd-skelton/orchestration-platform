## Why

Run m1-intake-refresh-20260914T1635 stopped ISS-147 with `reviewer-malformed`
after two reviewer launches that both completed a real review of candidate
e535d57f413db9c07556af53f61389053aedffd1 and returned verdict PASS with one
note finding and a G0 answer. The first final message was valid JSON matching
the output schema, but `dispatch-adapter.ts` also requires
`JSON.stringify(verdict).length <= MAX_TERMINAL_SUMMARY_LENGTH` (2000), and
that verdict was 2302 characters. The reviewer prompt in `flow.ts` never states
the cap; only the author prompt does. The retry was under the cap but placed
one sentence of prose before the JSON, which `JSON.parse` on the whole message
rejects. Both terminals are preserved under
`/root/orchestration-m1/runtime/m1-intake-refresh-20260914T1635/iss-147-attempt-1/source`.
Todd's model ruling (#368) places `claude-opus-5` high as the self reviewer;
this envelope is what blocks that placement, and a bootstrap exception keeps
`gpt-5.6-sol` high as reviewer until this issue lands.

## Done when

- The reviewer prompt states the exact envelope: the final response is the
  JSON object alone, and its serialized length is at most
  `MAX_TERMINAL_SUMMARY_LENGTH` characters; findings and G0 must be written
  to fit. The author prompt is unchanged.
- Verdict extraction accepts the last complete top-level JSON object in the
  final agent message when text precedes it; text after the object, no
  object, more than one object, or an object that fails the existing key,
  identity, head, and enum checks remains `malformed-worker-verdict`. The
  schema stays strict; only the framing tolerance changes.
- An over-length but otherwise valid verdict is still malformed, and the
  existing single automatic retry supplies the observed length in its retry
  context so the reviewer can shorten rather than guess.
- Regress both preserved terminals as fixtures: the 2302-character valid
  verdict is rejected only for length with that reason in the terminal
  summary, and the prose-prefixed verdict is accepted. Cover a verdict with
  trailing prose, two objects, and no object.
- docs/loop.md documents the envelope and the extraction rule.

## Out of scope

Raising or removing the length cap, changing the verdict schema or the
findings shape, per-model prompts, retry budget changes, and any change to
author verdict handling.
