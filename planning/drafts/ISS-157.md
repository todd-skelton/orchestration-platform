  moves. Add one optional loop-config recovery descriptor, outside original
  source fingerprints: repository/run/issue/attempt, original candidate and
  stopped delivery head, stop path/digest/reason, failing terminal/log identity,
  landed repair SHA and host's independent-review/hosted-green evidence reference.
  Host explicitly binds that repair to this stop. Before work, resolve retained
  identities, fetch main, prove repair in main but absent from stopped base/head.
  Support only `gate-host-failed:<gate>` / `gate-attribution-unknown:<gate>` in
  ordinary native delivery. Work/base stops, untyped legacy failures, accepted
  terminal replans and other reasons refuse. Evidence: local-Git queue positive
  plus single-variable negatives for absent/wrong authorization, run/issue/
  attempt/head/stop mismatch, unchanged/unavailable main, absent/already-included
  repair and work stop. All negatives launch/publish nothing.
- **AC2: Once, preserving history.** Reserve exact authorization and continuation
  location before work via existing single-writer persistence. Replay resumes it;
  changed IDs/main never renew this stop's allowance. Original stop/log/terminal,
  source/review, attempts and participants remain intact; no legacy rewrite.
  New failures have separate stop records, never overwriting/reactivating the old
  grant. This slice issues no second recovery. Evidence: restart after reservation,
  integration, author/reviewer launch and gates; compare original bytes and
  exactly-once launch charges.
- **AC3: Native continuation.** Reconstruct immutable original candidate/review,
  retain prior gate-correction/result and refresh/conflict usage, and enter native
  refresh. Rebase unpublished work; published work retains forward ancestry/lease.
  Only supported conflicts use the existing bounded author, never a new
  implementation author or host patch. Fresh independent DELTA covers exact
  source-to-current-main result using original review/trace, failed gate and repair
  provenance. Prior PASS/clean merge is not authority. Evidence: queue/refresh
  ancestry, launch-input and exact-review tests; stale PASS and spent conflict/
  native-launch ceilings refuse. No attempt, gate-correction, conflict, launch or
  worker-retry count/ceiling resets or increases.
- **AC4: Fresh delivery.** After DELTA, rerun all local gates, including previously
  green and after-mirror, into new continuation/refresh evidence. Main movement
  requires ordinary new DELTA/gates, not new recovery. Observe mirrors/reconcile
  publication intents; preserve PR #490 and remote-head lease. Hosted checks,
  landing and applicable deployment bind final head. Evidence: saved-stop through
  publication integration with synthetic effects; stale receipts, failed gate
  and wrong remote head forbid publication. Existing correction policy remains
  bounded, not renewed.
- **AC5: Replay and siblings.** Cover initial, review-repaired, gate-corrected and
  refreshed sources, before/after mirror and pending/completed publication.
  Standalone/legacy behavior stays unchanged. States: stopped (inert), reserved,
  integrating/observing worker, reviewed/fresh gates, hosted delivery, complete
  OR new stop. Resume workers; completed replay has no launch/publication/merge;
  failed replay stays stopped. Evidence: queue/supervision saved-selection and
  pending/completed learning-note replay fixtures, not only refresh unit tests.
- **AC6: Land and prove saved-run progress.** Exact-head native gates below and

  runtime/candidates nor start loops. Progress is not delivery/M2 completion.
