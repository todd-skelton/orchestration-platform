## Done when

- **AC1: Exact admission.** No authorization means the same stop even if main
  moves. Optional config authorization outside source fingerprints
  carries only `stateDirectory` (saved stop), `candidateHead` (stopped head),
  `repairSha` (landed repair), `authorityUrl` (grant/review/hosted-green evidence).
  Derive repository/run/issue/attempt/candidate/history from records; path/reason:
  `accepted.stateDirectory/gate-stop.json`, and logs/terminal from
  `gate-<sha256(gate)>`. No stop digest or hostile-state guards (loop rule 9).
  Fetch main; prove repair in main but absent from stopped base/head.
  Support only `gate-host-failed:<gate>` / `gate-attribution-unknown:<gate>` in
  ordinary delivery. Work/base, legacy, terminal-replan and other stops refuse.
  Local-Git queue positive proves derived paths. Single-variable negatives (no
  launch/publication): absent/wrong grant, head mismatch, unchanged/unavailable
  main, absent/already-included repair, work stop. No derived-field mismatch tests.
- **AC2: Once, preserving history.** Single-writer reservation precedes work;
  replay resumes it; IDs/main changes never renew it. Original stop/log/terminal,
  source/review, attempts and participants remain intact; no legacy rewrite.
  New failures retain separate stops; no second recovery.
  Evidence: restart after reservation/integration/author/reviewer/gates; compare
  original bytes and exactly-once launch charges.
- **AC3: Native continuation.** Reconstruct immutable original candidate/review,
  retain gate-correction/result and refresh/conflict usage. Native refresh rebases
  unpublished work; published work retains forward ancestry/lease.
  Only supported conflicts use the bounded author, never implementation authoring
  or host patches. Fresh independent exact-result DELTA inherits original review/
  trace, failed gate and repair provenance across source-to-current-main.
  Queue/refresh ancestry, launch-input and exact-review tests reject prior PASS/
  clean merge as authority and refuse spent conflict/native-launch ceilings.
  No attempt, gate-correction, conflict, launch or
  worker-retry count/ceiling resets or increases.
- **AC4: Fresh delivery.** After DELTA, rerun all local gates, including previously
  green and after-mirror, into new continuation/refresh evidence. Main movement
  requires new DELTA/gates, not recovery. Observe mirrors/reconcile
  publication intents; preserve PR #490 and remote-head lease. Hosted checks,
  landing and applicable deployment bind final head. Synthetic saved-stop-to-
  publication integration proves stale receipts, failed gates and wrong remote
  heads forbid publication. Correction allowance is not renewed.
- **AC5: Replay and siblings.** Cover initial, review-repaired, gate-corrected and
  refreshed sources, before/after mirror and pending/completed publication.
  Standalone/legacy behavior stays unchanged. States: stopped (inert), reserved,
  integrating/observing worker, reviewed/fresh gates, hosted delivery, complete
  OR new stop. Resume workers; completed replay has no launch/publication/merge;
  failed replay stays stopped. Prove via queue/supervision saved-selection and
  pending/completed learning-note replay fixtures, not refresh tests alone.
- **AC6: Verified native handoff.** Author/review evidence includes exact-head
  native gates in the verification plan, with full outputs independently inspected.
