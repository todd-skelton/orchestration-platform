## Decision

Quality profile: `core-library`. G0: retain every current lifecycle validation
boundary and reduce only provably duplicate reads within each invocation.
Start by reusing the just-read repository common directory rather than querying
it again immediately. If measured savings require it, combine compatible Git
reads within that same cwd/invocation, preserving Git's own resolution semantics.
Do not parse repository config files as a substitute for effective Git URLs.
Keep per-worktree fetch AND push URL validation: sharing a common directory does
not prove equal worktree-specific config, URL rewrites or environment resolution.

Rejected alternatives: repeated unchanged-head CI runs explain no cost;
cross-call caching or removing per-draft checks can admit intervening drift;
a general Git batching service is unnecessary for this one boundary.
Accepted downside: small call-local parsing/composition may need more focused
tests. Revisit if unchanged-gate measurements show insufficient savings, or
batching cannot preserve meaning; report the unresolved blocker, not a global
optimization, cache, timeout increase or diagnosis-only PASS.

   Exercise separate controller repositories and same-checkout controller/root,

   Real Git still resolves URLs and common directories. No adapter-global,

   redundant work; reverting freshness handling fails the relevant drift test.
4. **AC4 Final-head qualification.** Run complete `delivery-adapter.test.ts`,
