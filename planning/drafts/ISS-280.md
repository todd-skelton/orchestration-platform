## Why

The M2 pilot `m2-pilot-137-20261027-r4` stopped before review on
`cs-10415` with `gate-attribution-unknown:verify:static:scoped`. The
[pilot stop comment](https://github.com/chase-sets/chase-sets/issues/10415#issuecomment-6488591760)
matches `cycle-1-stop-2.json:4,13-14,51` under
`/root/orchestration-m2/runtime/m2-pilot-137-20261027-r4/` in Ubuntu.
That historical runner did execute; today's defect is different: a fresh
delivery asks pnpm to run a script the product no longer defines.

At platform `cde11e77198cc0c13b5baaf8a4861cd330f9175e`,
`adapters/chase-sets.mjs:475-477` still selects `verify:static:scoped` and
`typecheck`. `scripts/dogfood/delivery-adapter.ts:59-60` still parses the
retired gate's `[VERIFY_STATIC_RUN]` markers, and
`scripts/dogfood/queue.ts:6952-6953` still keys executor repair on its stop.
ISS-192, ISS-228 and ISS-229 attributed or recovered failures of that script;
they did not replace it. ISS-273 addresses retained log completeness, not
gate selection, and is not a prerequisite.

Chase Sets already supplied the replacement checks in
[#10914 Make lanes run cheap pre-push checks that mirror hosted Prettier and test-file Typecheck instead of verify:static:scoped](https://github.com/chase-sets/chase-sets/issues/10914).
[#10940 Remove the retired verify:static:scoped lane gate after cheap pre-push checks land](https://github.com/chase-sets/chase-sets/pull/10940)
merged on 2026-11-02. At Chase Sets `107f3b0ad2442db62fc6e754f01a665c50bcda39`,
`package.json` has no `verify:static:scoped` entry and
`scripts/verify-static-scoped.mjs` does not exist. The product's scoped checks
are documented in `AGENTS.md:3`; `.github/workflows/platform-pr.yml:151-176`
runs hosted `verify:static` when static proof is required.

## Decision

The pre-release adapter serves one developer on one machine and must not invoke
checks the product retired. The simplest alternative is to drop the obsolete
gate and rely on hosted checks alone. Keep fast feedback by running the existing
product pre-push checks separately, deleting scoped-static-only attribution,
and leaving hosted CI authoritative. This accepts that broad static failures
may first surface in hosted CI. Revisit if a delivery at current Chase Sets
main cannot pass those local checks or land through the existing exact-head
hosted proof path without the old gate.

## Done when

- A Chase Sets delivery based on current product main passes the local gates:
  `pnpm run typecheck:changed`, `pnpm run format:check -- --changed`, and
  `git diff --check` over the committed candidate delta, not the clean worktree.
  Candidate checks use the existing pinned changed scope; the two product
  scripts already accept `CHANGED_FILES_JSON`. Capture commands, base and head,
  and exit status on an isolated delivery, not by resuming the pilot.
- No active Chase Sets delivery gate, prompt, or recovery path references the
  retired script. Remove static-only marker parsing and executor-repair special
  handling in `delivery-adapter.ts` and `queue.ts`; retain same-command base
  attribution and correction for gates that still run. Historical stop records
  and evidence are left unchanged and grant no new recovery authority.
- Focused adapter and delivery tests exercise the new commands and candidate
  scope in a fixture with no retired script, and retain regression coverage for
  supported-gate failure attribution and unchanged hosted landing requirements.
  Update `docs/loop.md` to describe the new local gates and retire obsolete
  procedure. At landing, record the exact-head hosted `PR Required` result and
  `Static Source Checks` when selected by the existing workflow; a local pass
  does not substitute for hosted static proof.

## Out of scope

No new aggregate gate, recreated runner, product or hosted-workflow change,
self-adapter change, or live executor rollout. Scoped compiler and explicit
one-worker non-DB focused tests run directly. Preserve heavy admission for
full-workspace, DB and browser checks, including the product format check's
full-tree fallback; exit 73 is non-execution, not a pass or an attempt.
