## Context and evidence

Decision #302's readiness audit (§3, CF-2) identifies the on-disk shape of a
recorded GitHub API transcript and the pure reducers over it as a
credential-free prerequisite for `ISS-036`'s live producer window. This issue
builds that shape and those reducers with no HTTP client and no credential.

## Scope fence

In: one transcript row per API exchange carrying the exact request (REST
`route`/`method`/query, or GraphQL document/variables), the raw response
bytes, the raw `Link` header bytes, the `ETag`, `observedAt`, and status. Pure
functions derive every receipt cell the ledger says is derived:
`requestIdentityDigest` (`contract-decisions.md:6866-6870`), first-page and
every GraphQL page `requestDigest` (`:6874-6883`), `completeReductionDigest`
(`:6903-6910`), `terminalPaginationDigest` (`:6920-6926`), and each of the
seven recomputable `reducedValueDigest` projections (`:6948-6958`). Also the
archive shape that retains the opaque leaves' preimages: request material,
response bodies, raw Link headers, later REST request bytes, and the
`PULL_REQUEST`/`PULL_REQUEST_REVIEWS` reducer preimages (`:6959-6965`,
`:6886-6890`).

Out: any HTTP client, any authentication, any live pagination execution. The
reducers read files, never a socket.

## Acceptance criteria and evidence

1. For a hand-authored nine-purpose transcript fixture, every derived digest
   recomputes and `parseRepositoryProtectionReceipt` accepts the assembled
   receipt.
2. Deleting any one reducer makes a committed mutant survive and therefore
   fail the suite.
3. A reducer that invents a `Link` relation the transcript did not carry, or
   that reads `nextRequestDigest` from its own output, is refused by a named
   negative vector.

## Independent review packet seed

Attack a reducer that invents a `Link` relation the provider omitted
(`contract-decisions.md:6828-6831`); a page count presented as terminal proof
(`:7112-7114`); a reducer that reads its own prior output as if it were a
fresh observation; an archive shape that drops a required opaque preimage.

## Does not claim

That GitHub supplied a `Link` header, that a producer followed it, or that
any capture is complete. "Parser success proves only an internally linked
claimed chain" (`contract-decisions.md:6888-6890`).
