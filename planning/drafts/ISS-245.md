## Decision

Every actual native launch must remain charged across earlier-cycle continuation and config changes without rewriting retained evidence.
The simplest alternative is to fix only future history seeding, which leaves this already divergent run permanently inadmissible.
Use the existing native history readers to preserve continuity and recognize only the evidenced single-author hosted-continuation fork, and extract the existing complete admission evaluation for a read-only preflight.
Accept a narrowly bounded historical accounting projection with explicit original-to-effective ordinal provenance, while keeping raw records, packet digests and existing reservations unchanged.
The choice is wrong if an unexplained fork becomes admissible, any charge or allowance disappears, old reservations change on replay, or preflight can write or accept a packet that real admission rejects against identical inputs.
