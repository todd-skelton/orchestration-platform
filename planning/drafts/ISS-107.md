## Why

Repository-specific rules live in `scripts/dogfood/self-delivery-policy.mjs`:
the repository name, required check names, branch prefix, PR body, squash
merge, and the planning mirror. Chase Sets needs different values for each.
One adapter module per repository keeps the loop neutral.

## Done when

- `adapters/<name>.mjs` exports `selectCandidates`, `branchName`,
  `pullRequest`, `requiredChecks`, `mergeMethod`, `afterMerge` for post-merge
  verification, and an optional `mirrorPlanning`.
- `loop.json` names the adapter; the loop imports it and calls only those
  functions.
- `adapters/self.mjs` reproduces today's behavior for this repository and
  `self-delivery-policy.mjs` is deleted.
- Tests exercise the loop against a fake adapter and the self adapter.

## Out of scope

The Chase Sets adapter itself (ISS-108).
