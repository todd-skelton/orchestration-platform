## Context and evidence

Decision #302's readiness audit (§3, CF-1) decomposed `ISS-036` into
credential-free sub-slices that need no live GitHub credential and no
provider mutation. This is the first: a pure builder over the closed
`bootstrap-verifier-anchor/v1` value family
(`docs/architecture/contract-decisions.md:6996-7047`) that ISS-054 already
parses and digests (`parseBootstrapVerifierAnchor`,
`computeBootstrapVerifierAnchorDigest`,
`packages/contracts/src/verifier-anchor.ts:13-184`), plus the refusal corpus
that exercises it.

## Scope fence

In: a pure builder that assembles the ten-member anchor from operator-supplied
per-OS asset facts plus the fixed literals, canonicalizes it, computes
`Danchor` via `computeBootstrapVerifierAnchorDigest`, and writes/reads it at a
caller-supplied path whose canonical form is
`<state-root>/bootstrap/verifier-anchor.json`
(`contract-decisions.md:7063-7065`). The refusal corpus: absent, duplicate, or
substituted OS rows, a mutable selector, a custom root, an executable-path
substitution, and the combined anchor+verifier+bundle substitution
(`planning/drafts/ISS-054.md:149-154`; `planning/drafts/ISS-036.md`'s
negative-control list).

Out: any download, checksum computation over a real release, CLI acquisition,
Sigstore/TUF verification, or credential of any kind. `ISS-036` supplies the
real GitHub CLI 2.93.0 asset/checksum facts live; this issue only builds and
tests the pure assembly and refusal logic around them.

## Acceptance criteria and evidence

1. Round-trip byte goldens: the same operator-supplied facts, canonicalized
   and written, read back byte-identical.
2. `Danchor` recomputed from the written bytes equals
   `computeBootstrapVerifierAnchorDigest` applied to the same canonical
   record.
3. Every refusal vector (absent/duplicate/substituted OS row, mutable
   selector, custom root, executable-path substitution, combined
   anchor+verifier+bundle substitution) returns `ok:false` with the exact
   issue code; a deletion mutant per vector fails the suite.
4. The ISS-054 closed same-realm mutable/sealed/frozen corpus passes and the
   proxy/cross-realm/hole/symbol/accessor/custom-iterator hostile-reflection
   corpus refuses before any provenance read, for every envelope this builder
   touches.
