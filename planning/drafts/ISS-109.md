## Why

Chase Sets routes some work to Claude lanes. The loop dispatches only through
the Codex CLI today. Pull this issue only when a Chase Sets issue actually
routes to Claude, or when a learning note from ISS-110 says a Codex author
could not complete a class of work that the incumbent gave to Claude. Until
then it stays unlabeled.

## Done when

- `scripts/dogfood/dispatch-adapter.ts` gains a second adapter kind that
  launches `claude` non-interactively in the worktree with the same sandbox
  intent (author may edit source only; reviewer read-only), the same
  environment allowlist and temp root, and the same JSON verdict schema.
- `loop.json` selects the adapter per role.
- Preflight refuses an unavailable or incompatible CLI before launch.
- Tests cover launch arguments, environment, and verdict parsing with a fake
  process.

## Out of scope

Model routing policy. Mixing adapters within one attempt.
