## Decision

Planning must reject exactly the criteria shapes that the self adapter cannot consume.
A second heading-only regular expression in the checker is simpler locally but would retain two definitions and accept empty sections.
Choose one pure criteria extractor shared by planning validation and the self adapter, preserving the existing grammar.
Accept that previously incomplete synthetic planning fixtures need real criteria to remain valid.
The choice is wrong if the two consumers can disagree on consumability or any existing accepted criterion changes text or order.

## Done when

1. **AC1 One criteria definition.** Move the existing heading/list extraction
   into one pure helper in `scripts/planning/check.mjs`, with its declaration
   in `check.d.mts`, and use it from `adapters/self.mjs::issueContext` through
   the existing dependency direction. Validate every registered draft with
   that helper, irrespective of readiness or milestone. Missing heading or
   zero parsed items makes `pnpm planning:check` exit nonzero with
   `PLANNING_CONTRACT_MISMATCH`, the offending draft path and the required
   `## Done when`/supported-items expectation. Direct adapter calls retain
   `selected-issue-criteria-missing`. No second heading or list grammar, new
   Markdown dependency, or runtime import into the planning checker.
   Evidence: shared-helper call-site inspection and planning CLI negative
   control in a temporary, otherwise valid planning tree.
2. **AC2 Regress the actual draft shape.** A literal fixture derived from
   PR #647's ISS-206 draft, including its three ordered criteria under
   `## Acceptance`, passes all unrelated planning rules but fails the new
   criteria check. Changing only the heading to `## Done when` passes and
   the real adapter returns exactly those three criteria with unchanged
   continuation text and order. Freeze the other inputs; temporarily bypassing
   just the new validation must make the negative regression fail. Also
   reject a missing heading, empty section, prose-only section and unsupported
   list syntax; preserve `-`, `*`, `+`, top-level `N.`, CRLF, indented

   Evidence: extend `test/planning-contracts.test.ts` and the existing
   `self criteria` cases in `test/dogfood/repository-adapter.test.ts`, not a
   test-only alternate parser or dependence on a moving live draft.
3. **AC3 Preserve other contracts.** Inventory the callers below and update
   only synthetic success fixtures that omitted consumable criteria; keep
   negative fixtures discriminating their original rule. The current real
   draft corpus passes without bulk draft edits. Fresh selection, selected

   ordinary boundaries; saved pins, legacy reads, fingerprints, attempts,

   planning-check description in `docs/loop.md` to state the new guarantee.
