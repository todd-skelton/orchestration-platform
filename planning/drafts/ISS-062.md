## Context and evidence

Decision #302's readiness audit (§3, CF-7) identifies this as the last
credential-free sub-slice: it amends the ISS-000 frozen scaffold (the audit's
Gate 6 footprint gap) so `probe:self-host-github` and
`probe:self-host-github:verify` stop being not-implemented wrappers, and it
writes the operator runbook `ISS-036`'s live window follows. It depends on
every other credential-free sub-slice because it wires their output together
into one offline verifier and runs `ISS-058`'s matrix against it.

## Scope fence

In: `probe:self-host-github:verify` as a pure offline verifier over
`.artifacts/self-host-github-probe` (`.artifacts/` is gitignored). The
runbook: the operator window sequence (O1-O11 as forecast in
`planning/drafts/ISS-036.md`), the exact chronology fences, the read-back
scripts' expected outputs, the abort conditions, and the scrubbing rules for
the teardown report bound to probe/test digests. The `package.json` plus
`scripts/planning/check.mjs:146-166` `implementedRootScripts` amendment, in
one reviewed change naming `ISS-036`, per
`docs/planning/work-model.md:49-53`.

Out: any live execution. The runbook is text plus a verifier, not an operator
agent.

## Acceptance criteria and evidence

1. `pnpm run planning:check` passes after the scaffold amendment (the exact
   verification wrapper strings for `probe:self-host-github` and

   default to this issue's real command).
