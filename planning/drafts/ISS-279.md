without mutation; no supported disposition was found.

## Decision

Already-admitted fresh work must publish without replacing prior-run evidence.
Closure retains the all-state collision and automatic supersession adds mutations.
Scope new ordinary self names by run and save the choice in setup, retaining legacy/continuation identities.
Accept one PR per run and historical PRs awaiting separate disposition.
A smaller supported route preserving identity, accounting and gates would reverse this choice.

## Scope fence

Scope: self naming/composition, saved choice, tests and `docs/loop.md`.
New ordinary self attempts use
`codex/run-<sha256(run)>/<lowercase-issue-key>-attempt-<absolute-attempt>`.
The hash is full lowercase SHA-256 of the exact UTF-8 run string, as in the
existing local rule; always include the attempt suffix, including 1.

Non-goals: stale-PR mutations, force-updates, ref deletion, worktree reuse,
findings transport, admission/retry/parking/charges/ceilings/ladders, Chase Sets
naming, installation or live starts.

## Decisions already made

- Add optional `run` to repository `branchName`; only new ordinary self supplies
  it. Validate supplied run against the existing contract; invalid refuses,
  omission means legacy/special naming. Chase Sets ignores it.
- Add optional `publicationBranch` to existing setup config/plan production,
  validation and exact replay. Save before source work using existing pre-mutation
  plan persistence. Read saved setup BEFORE naming: present selects its validated
  choice; absent means legacy without backfill. Legacy local branches are already
  scoped, so cannot identify publication policy. Keep fingerprints and old bytes.
- Same-run ordinary next attempts use distinct absolute-attempt names. Both
  `queue.ts:1873` (verification-only) and `:3072` (composition) are callers:
  verification-only for a new source must recover its saved publication identity;
  legacy verification-only keeps its current identity. Existing accepted-replan,
  integration/terminal-admission and explicit published continuation policies
  stay unchanged, including forward-only refresh of the selected PR.
- Keep native all-state lookup, exact-head checks and leases on the NEW name:
  reconcile exactly or refuse, never choose another suffix. The executor owns
  publication/landing; old review/green supplies no new authority.
  Before initial push require remote ref absent or exactly candidate (lost push);
  otherwise refuse. Add this check in the native publisher.
