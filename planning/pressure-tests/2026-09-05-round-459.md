## Scope

One new private module, `probes/portable-primitives/experiment/controls.mjs`,
which produces ordered control records for exactly the twelve landed control
IDs, in the landed order, derived from `hostedNativeLockControlIds` and never
re-typed. For the nine captured-input rows it composes one honest counterpart
and one named mutant of the same capture, runs both through the real landed
guard, and emits `REFUSED` only when the guard accepted the honest counterpart
and refused the mutant. For the three witness-dependent rows it emits the
nullable arm derived from stable prerequisite evidence; the module contains no
path from those rows to `REFUSED` or `VIOLATED`, because this slice adds no
call-interception fixture. It then writes the ledger's fixed files
`controls/<controlId>/input.json` and `controls/<controlId>/observation.json`
under the archive root, honouring the rule that an unavailable row requires its
observation and forbids its input.

The module's exported, package-private surface is `nativeLockControlArms`,
`nativeLockControlPrefix`, `nativeLockControlPrerequisiteFields`,
`nativeLockControlPaths`, `nativeLockControlGuards`,
`deriveNativeLockControlPrerequisiteArm`, `buildNativeLockControlCensus`,
`checkNativeLockControlCensus`, `writeNativeLockControlFiles`, and
`runNativeLockControlPhase`. No public package export, schema, dependency,
installed tool, production consumer, committed binary, or workflow trigger is
added.

Two mechanical consequences are recorded honestly rather than worked around.
First, Node does not rewrite a `.mjs` import specifier onto a TypeScript
source, so the module reaches the two sub-slice 3.1 guards, the landed control
ID list, and the three capability parsers through their real `.mts` and `.ts`
specifiers. Second, `tsconfig.json` sets no `allowJs` and the experiment tree
carries no declaration file, so `tsc` reports TS7016 for a `.test.ts` importing
any experiment `.mjs`; the test suppresses that one diagnostic per import and
binds each module to a locally declared shape, because adding a `.d.mts` would
exceed this slice's exact five-file footprint.
