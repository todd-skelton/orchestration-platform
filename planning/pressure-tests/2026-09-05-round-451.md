## Packet A — closed typed structure

Packet A source is artifact attempt 3 and cannot start until this plan lands
after independent semantic review attempt 2 PASS. Its parser has two internal
stages, both inside the structure-only module:

1. **Closure/type stage.** Snapshot the root once using the repository hostile-
   reflection primitive. Each child record has its own exact parser returning
   `ParseResult<SpecificRecord & ContractRecord>`; each array parser returns a
   typed success/refusal result and invokes the child parser for every dense
   element. The stage may read a successfully closed parent field only to pass
   that value to its child parser. It performs no comparison with another
   record, no `.find`, no projection and no digest. It never casts a failed child
   or inserts `undefined` into a nominal typed row. Any child issue prevents the
   typed receipt tree from being constructed and returns a sorted, frozen
   refusal.
2. **Local structure stage.** Only after every record and array in the complete
   tree has a successful typed result, validate scalar grammars, literal and
   nullable cells, dense bounds, codepoint/UTF-8 order, uniqueness and structural
   censuses over those typed values. Local time comparisons are limited to
   fields in the same typed record, such as receipt issue/expiry and observation
   start/completion. Request and page union branches are classified from each
   record's own detached field census; a raw request discriminator never selects
   another raw record's parser. Any issue returns refusal. Cross-record equality,
   chronology, pagination handoff, semantic projection and digest work remain
   absent.
