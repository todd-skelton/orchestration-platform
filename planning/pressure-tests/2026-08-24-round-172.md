## Findings and constructibility

No finding requires replanning.

- GitHub-hosted Linux and macOS VMs provide passwordless `sudo`, and hosted
  Windows VMs run as administrators with UAC disabled. That is sufficient for
  the ledger's bounded stable-only create/drop/ACL/census/delete operations;
  the candidate UID/SID receives none of that authority.
- Linux can allocate an unused non-login UID, clear supplementary groups, drop
  credentials before candidate execution, census all real/effective/saved/
  filesystem UID appearances through `/proc`, signal residual processes, and
  refuse until both the process census and account lookup are empty.
- macOS can create an unused local non-login UID under the privileged adapter,
  drop supplementary groups and credentials, and use the kernel process table's
  effective-UID and real-UID selectors for a complete repeated kill/absence
  gate before local-account deletion. Failure or unreadability refuses.
- Windows supports a fresh moniker-derived AppContainer package SID, explicit
  DACL read/execute grants, an AppContainer process created with security
  capabilities, profile deletion, and process/credential isolation. A suspended
  or atomic job-associated launch prevents pre-assignment execution. A nested
  non-breakaway Job Object with `KILL_ON_JOB_CLOSE` contains descendants on
  hosted Windows; neither breakaway flag is admitted, and the adapter proves
  the job empty before revoking ACLs and deleting the profile.
- Node is a normal Win32 executable that may be launched under an AppContainer
  token when its runtime, exact candidate artifact, RPC runner, pipe handles,
  and scratch have the required least access. The proposed suite needs no
  network/device/credential capability. Missing runtime access is
  `UNSUPPORTED`/refusal, not permission widening or same-principal fallback.
- On every OS, the stable parent owns the anonymous-pipe endpoints and parses
  candidate bytes as hostile data. A forged PASS, duration, selected head,
  partial/duplicate response, inherited writer, nonterminal process, or pipe
  ambiguity cannot bypass stable expected-value equality, stable monotonic
  timing, terminal exit, and empty-census gates.
- Unique per-job identities, absence-before-create, identity-checked roots,
  ACL revocation before deletion, complete residual-process cleanup, and
  absence-after-delete close UID/SID reuse and stale-ACL races. Kernel
  compromise remains the explicit boundary; same-principal Node permissions,
  scanning, `vm`, or candidate self-report are not substitutes.

These are implementation obligations, not claims that exact HEAD already
contains the new principal adapters. The existing same-principal walk path must
be replaced; it is not authorized as evidence for the repaired design.
