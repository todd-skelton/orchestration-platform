| `OP-R28-003` — Bootstrap abort required an authority-bearing request artifact with no declared producer. | Changed the sole command to `abort --input <bootstrap-install-input/v1> --output <bootstrap-abort-receipt/v1>`. It derives deterministic transaction paths and reads authoritative state itself; no separate abort request exists. |
