## Blocking finding 1: parent transition is not crash-recoverable

`packages/conformance/src/linux-principal-dac.py` changes a profile with two
separate syscalls:

```text
fchown(handle, uid, gid)
fchmod(handle, mode)
```

For the execution parent, a process death between them leaves one of two exact
recoverable intermediate profiles:

1. during PREPARE, `stableUid:<privateGid> 0700`; or
2. during RESTORE, `stableUid:stableGid 0710`.

The durable intent exists before either transition, and both intermediate
states are less permissive than the final grant. However, `open_handles` admits
the parent on RESTORE only when it is exactly the original profile or the final
granted profile. Recovery therefore refuses either intermediate before
`restore()` can repair it. This violates Round 173's pre-mutation reversal rule
and Round 176's explicit requirement that every partial parent grant/restore
crash prefix retry idempotently.

### Required repair

- Keep the durable request canonical and original-profile-bound.
- On RESTORE only, admit the exact closed set of four parent profiles:
  original, final grant, PREPARE-after-`fchown`, and
  RESTORE-after-`fchown`. Continue to refuse every other UID/GID/mode.
- Admission must compare the same retained and fd-relative-reopened parent
  device/inode/path/type identity; it cannot weaken ancestor custody.
- A third-profile observation must be reported as an ambiguity, repaired to
  exact original, and retain the intent for one successful clean retry. Only a
  later exact original-profile pass may remove the intent after its directory
  durability barrier.
- Exercise the actual `main -> open_handles -> restore` control flow for both
  intermediate profiles. A direct unit call to `restore()` with preconstructed
  handles is insufficient because the current defect occurs before that call.
  Delete each admitted intermediate independently and inject process loss after
  each parent syscall.

Reordering `fchown` and `fchmod` does not remove the two-syscall crash prefix;
it only changes which safe intermediate appears first. A world grant, best-
effort cleanup, ignored intent, same-principal fallback, or wider accepted
profile set is not a repair.
