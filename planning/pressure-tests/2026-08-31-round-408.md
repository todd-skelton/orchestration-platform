## Scope and decisions

The smallest coherent remaining public group is orchestration-event/v1,
event-journal/v1, reduced-state/v1 and cycle-receipt/v1. Separating them leaves
unchecked bytes, a partial output union, an unauthenticated reducer or a receipt
hash cycle. Mandatory readiness input remains in
TEMP/orchestration-journal-family-readiness-20260831.md.

- Event v1 is complete for the admitted PROJECT path and every current typed
  output/composite/skip. Missing release producers trigger versioned replan.
- The journal is one length-framed append-only stream, not NDJSON or rewritten
  JSON. Genesis requires actual create-once fresh-root admission.
- Every step has immutable STARTED and optional TERMINAL events. Physical prefix,
  position, predecessor and owning output identities are recomputed.
- Replay retains pending external identity/resources/targets and refuses
  UNKNOWN padding, duplicate effects and false prefixes.
- Ordinal15 is upstream-only: pre15 state -> STARTED -> terminalizing state and
  prefix -> receipt -> TERMINAL event -> final replay.
- Earlier UNKNOWN/live/resource-unknown paths end at reduced UNKNOWN without
  starting15 or fabricating an UNKNOWN cycle receipt. A future post-STARTED
  terminal-unknown producer requires versioned replan.
