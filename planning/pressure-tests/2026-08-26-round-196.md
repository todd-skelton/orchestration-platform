## Exact target classification

```text
captured execution root                                      -> role 4
captured execution root + "\\node.exe"                       -> role 1
captured execution root + "\\rpc-runner.mjs"                 -> role 2
captured execution root + "\\candidate.mjs"                  -> role 3
```

It constructs each child path with the same bounded append primitive and uses
full `wide_equal` equality. A source, parent, state record, journal final,
sibling, or unknown object with the same basename cannot classify. A moved or
substituted handle is observed by its live final path before the real
disposition and therefore becomes unidentified rather than inheriting a cached
role.

## Exact pending-journal exception and stale handles

On a successful open of a parsed pending OPWX path, the fixture stores the
returned handle, exact opened path, and parsed phase. A disposition is excluded
as journal rollback only if all of these remain true at the live boundary:

- the current final path parses as a pending OPWX phase;
- the disposition handle equals the stored pending handle;
- the parsed phase equals the stored active publication phase; and
- the live final path equals the exact captured opened path.

A pending-looking path outside the state root cannot satisfy this relation
merely by suffix. In the destructive cleanup call graph, the stored relation is
owned by the actual current publication handle; retained sources were opened
earlier, and each publication close clears the stored handle, first path unit,
and phase. `fixture_execution_CloseHandle` clears those values immediately
after calling the real close, including when the fixture then reports an
ambiguous close result. A later Windows handle-number reuse therefore cannot
inherit the exception.

Rename/substitution also fails closed: the classifier asks Windows for the
current final path before forwarding the disposition, then compares it with
the captured path. A final journal path has `pending == false`; an unknown or
stale handle whose path cannot be resolved sets unidentified state.
