## Blocking findings and smallest repair

### OP-R163-1 — alternating lifecycle equality deletion survives

Production correctly computes the only expected successor:

```text
IN_PROGRESS -> TERMINAL
TERMINAL -> IN_PROGRESS
```

and reports `edge:lifecycle` when the actual successor differs. An isolated
in-memory source mutant deleted only that comparison. All nine focused tests
still passed.

The current crossed-lifecycle fixtures are confounded:

- `inProgress0 -> inProgress2` is IN_PROGRESS→IN_PROGRESS, but it also skips
  ordinal 1, names `Dattempt(terminal1)` instead of `Dattempt(inProgress0)`,
  changes attempt ID, and changes descriptor digest;
- `terminal1 -> terminal3` is TERMINAL→TERMINAL, but it also skips ordinal 2
  and names `Dattempt(inProgress2)` instead of `Dattempt(terminal1)`.

Deleting lifecycle equality leaves those cases rejected by stale ordinal,
predecessor, and identity siblings.

The smallest repair adds two independently valid same-lifecycle inputs:

```text
I(A,0) -> I(A,1, predecessor=Dattempt(I(A,0)), same descriptor/context,
             nondecreasing time)

T(A,1) -> T(B,2, predecessor=Dattempt(T(A,1)), different attempt,
             same context, nondecreasing time)
```

Each must refuse solely because lifecycle does not alternate. The first alone
kills complete branch deletion; retaining both preserves branch-local
discrimination if the production check is later split.

### OP-R163-2 — same-attempt `attemptId` preservation deletion survives

Production correctly preserves both `attemptId` and `descriptorDigest` on
IN_PROGRESS→TERMINAL. A member-level in-memory mutant changed the preservation
array from:

```text
[attemptId, descriptorDigest]
```

to:

```text
[descriptorDigest]
```

All nine focused tests still passed.

The existing same-attempt negative mutates only descriptor digest. No fixture
changes terminal attempt ID while leaving lifecycle, descriptor, ordinal,
predecessor digest, transaction, source, and time valid. The TERMINAL→
IN_PROGRESS reused-attempt case tests a different rule and cannot kill deletion
of IN_PROGRESS→TERMINAL preservation.

The smallest repair adds:

```text
I(A,0) -> T(B,1,
            descriptor=same,
            predecessor=Dattempt(I(A,0)),
            context=same,
            time nondecreasing)
```

and requires refusal. No new equality or field is needed in production.
