## Finding removal

`OP-R90-001` is removed.

Both `validateBootstrapAnchorMutationBinding` and
`validateBootstrapAnchorConflictBinding` still take detached closed snapshots
of every public input and return their existing sorted, de-duplicated frozen
issue arrays for schema-invalid input. After successful parsing, each now
computes `Dba` once inside a local guard. A structurally valid anchor whose
stored global identity differs from the recomputed
`global-bootstrap-identity/v1` digest returns exactly:

```text
["anchor:globalBootstrapIdentityDigest:mismatch"]
```

The exception no longer escapes either public composition. The verified `Dba`
is then passed into the private `proposalValueIssues` helper for the current
and, where applicable, prior proposal/value graph. Conflict composition uses
the same verified digest for both losing and winning graphs and for all
conflict/tip equalities. This removes repeated throwing construction without
changing a public schema, issue namespace, digest domain, framed part, path,
export, or accepted lifecycle branch.

The guard is reached only after the anchor is a detached, exact-schema record
whose fields satisfy their closed scalar grammars. At that point the throwing
`computeBootstrapAnchorDigest` boundary distinguishes precisely the false
derived global identity. Direct digest construction remains intentionally
strict: `computeBootstrapAnchorDigest` still throws
`TypeError: globalBootstrapIdentityDigest:mismatch` for the same substituted
anchor, and constructors still throw for parser-invalid input.

```text

substituted mutation -> ["anchor:globalBootstrapIdentityDigest:mismatch"]
substituted conflict -> ["anchor:globalBootstrapIdentityDigest:mismatch"]
```

constructor continued throwing, and both substituted public compositions

committed regressions independently discriminate the mutation and conflict
paths; neither can pass because another graph mismatch happens first.

The first two harness attempts made zero source replacements because their

regular expression. Both aborted on the explicit zero-replacement assertion
