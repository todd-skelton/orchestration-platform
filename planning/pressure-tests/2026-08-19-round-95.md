## Blocking finding

### `OP-R95-001` — the ACTIVE review-core equality rejects valid successor-origin CONSUMED teardown

`packages/contracts/src/teardown.ts` now unconditionally requires
`selectedOwnerValue.successorReviewCoreDigest` to equal
`anchor.successorReviewCoreDigest` after its ACTIVE/CONSUMED branch handling.
That equality is required while the owner is ACTIVE: genesis owner ACTIVE and
anchor both carry null, while successor owner ACTIVE and anchor both carry the
same non-null `Dsrc`.

It is invalid after owner `CONSUME`. The normative owner lifecycle matrix and
`parseDestinationOwnerValue` require a CONSUMED owner value's review and
archive members to be null. A successor anchor, however, permanently retains
its non-null `successorReviewCoreDigest`. Therefore a valid successor
installation reaches teardown with:

- anchor `successorReviewCoreDigest = Dsrc`;
- owner CONSUMED `successorReviewCoreDigest = null`; and
- the exact selected CONSUMED anchor triple embedded in the owner.

An independent valid reconstruction used a successor anchor and owner ACTIVE
selection, then the ordinary valid anchor/owner CONSUMED selection and teardown
artifacts. It returned only
`selectedOwnerValue.successorReviewCoreDigest:mismatch`. The committed valid
CONSUMED test uses only a genesis anchor with a null review core, so it does not
exercise this lifecycle crossing.

This is not acceptance widening, but it is a fresh acceptance narrowing in the
round-94 repair and prevents the approved successor lifecycle from reaching
consumed teardown. The latest exact-head removal round is therefore not clean.

Smallest bounded remedy: scope the owner-to-anchor
`successorReviewCoreDigest` equality to the existing `lifecycle === "ACTIVE"`
branch. Retain every ACTIVE genesis/successor branch check and all CONSUMED
owner-to-anchor triple and predecessor checks. Add one focused acceptance test
for a successor-origin CONSUMED branch. No schema, path, digest, parser,
receipt, owner archive, RETIRED CAS, or other authority change is warranted.
