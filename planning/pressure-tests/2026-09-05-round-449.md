## Attempt, review, and park protocol

The fresh slice has exactly four artifact attempts:

1. This current-main-rooted plan.
2. Independent semantic review of the exact plan head. PASS is required before

3. Prettier-canonical source reconstruction in the exact four classifier files.
4. Independent exact-head source review by a different lane. It binds the
   complete four-file diff, retained semantics, integration census, diagnostic
   evidence, and deletion proof.

An attempt-2 BLOCK, attempt-4 BLOCK, surviving counterexample, or footprint
growth parks the slice immediately. There is no artifact attempt 5. A local
admission-gate failure before independent review is a lane defect: fix it
within the exact footprint and rerun the complete local gate set before review;
it does not increment the artifact attempt. A defect that cannot be fixed
inside the footprint parks the slice.

three hosted bootstrap jobs are mandatory. A hosted failure after PASS may use
only Decision #258's lane-hygiene exception when the complete logs isolate the
failure to Prettier canonicality or the declared current-main integration

continues; it is not artifact attempt 5. Any semantic, test, native, footprint,
workflow, provider, or authority failure parks the slice. Partial, missing,
moving, or contradictory job evidence is `UNKNOWN`, never eligibility for the
