disjoint path set, scans all three current worktree states before recording or
creating any selected worktree, then writes immutable per-role intent before
each Git or installer effect. Existing unowned paths/branches/worktrees, dirty

closed status/reason/phase, run/issue, approved heads, and selected worktree IDs.

interruption after mutation, repeated setup, known/unknown installer failure and
