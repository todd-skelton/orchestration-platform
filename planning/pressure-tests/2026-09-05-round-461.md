## Scope

One new private module, `probes/portable-primitives/experiment/control-fixtures.mjs`,
carrying the three stable-authored JavaScript call-interception fixtures for
`BYPASS_LOCK`, `PREMATURE_UNLOCK` and `RETAIN_AFTER_RELEASE`, and a bounded
edit to `probes/portable-primitives/experiment/controls.mjs` that wires the
control phase through the landed seam before the case phase.

Each fixture is a hostile-candidate stand-in that a spawned bare-Node child
runs. It loads only the already built `STABLE_WITNESS` addon through the landed
`loadNative` guard and takes real locks on the one fixed file; it adds no
native binary, no alternate candidate, no intentional inheritance, and no
holder-death or spawn command. `BYPASS_LOCK` never calls the lock and claims to
hold it; `PREMATURE_UNLOCK` unlocks with no parent release or death command and
still claims to hold; `RETAIN_AFTER_RELEASE` claims release and keeps the lock.
No candidate addon is loaded anywhere, and none is loaded in the stable parent.

The claim is never the evidence. `judgeNativeLockControlFixture(controlId,
witnessFacts)` takes the control ID and the stable parent's own witness facts
and nothing else, reduces them with the landed `lockDisposition`, and returns
`REFUSED` for the refuting disposition, `VIOLATED` for the corroborating one,
and a null verdict otherwise. A null verdict falls back to
`deriveNativeLockControlPrerequisiteArm` over the same stable prerequisite
facts the report carries, so a row with no usable witness keeps exactly the arm
sub-slice 3.2 already emitted.

The control phase runs one fixture at a time: `beginControl`, spawn the child
through the boundary, take its claim, `barrier`, the parent's own `tryWitness`,
close the child and its known resource on the fixed file, freeze the journal,
then the reset gate and the landed `resetControl`. The case phase is entered
only through `enterNativeLockCasePhase`, which refuses while the witness is
held or a resource is open. A child that never closes is left alone rather than
signalled, because signalling it would be a second holder-death attempt hidden
in a control; its resource stays open, the reset refuses, and the case phase
stays closed.

The new exported, package-private surface of `control-fixtures.mjs` is
`stableControlFixtureFiles`, `nativeLockControlFixtureCommands`,
`nativeLockControlDeathCommands`, `nativeLockControlFixtureClaimFields`,
`nativeLockControlFixturePolicies`, `nativeLockControlFixturePolicy`,
`checkNativeLockControlFixtureCensus`, `checkNativeLockControlDeathFreedom`,
`judgeNativeLockControlFixture`, `createNativeLockControlResourceLedger`,
`checkNativeLockControlReset`, `checkNativeLockCasePhaseEntry`,
`spawnNativeLockControlFixture`, `runControlFixturePolicy`,
`nativeLockControlFixtureWatchdogMs`, and
`runNativeLockControlFixtureChild`. `controls.mjs` adds
`nativeLockControlPhaseGates`, `runNativeLockControlFixturePhase`, and
`enterNativeLockCasePhase`. No public package export, schema, dependency,
installed tool, production consumer, committed binary, or workflow trigger is
added.

## Design consequences of the sub-slice 3.2 review receipt

Observation 1. `controls.mjs` is not loadable by bare Node, and the three
fixtures run as bare-Node children, so `control-fixtures.mjs` never imports it.
Its whole import graph is `node:child_process`, `node:path`, `node:url`,
`./facts.mjs` and `./io.mjs`; the test asserts that exact specifier set, that
the module carries no dynamic `import(`, and that a bare `node
--input-type=module` process imports it and reads its three policies.

Observation 4. Every caller-supplied boundary substitution now appears in the
retained observation: each `observation.json` carries a `substitutions` member
naming the substituted gate and guard keys, whether the spawn boundary was
substituted, and whether the seam was absent, the landed case context, or a
substituted seam. The seam kind is not caller-supplied: only
`runNativeLockControlFixturePhase` can brand a fixture result, and only a seam
that passes the landed `requireCaseContext` is stamped
`LANDED_CASE_CONTEXT`. A caller-supplied result is always `CAPTURED_INPUT` and
its evidence is always `SYNTHETIC_WITNESS_CALL_INTERCEPTION`.

Observation 5. The deferred halves of rows 8 and 11 are untouched and stay
disclosed in `observation.json`; this slice changes neither row.

Observation 8. Guard association is no longer positional only: each executable
row now declares its `controlId` and the module refuses unless it equals the
landed control ID at that position, and
`checkNativeLockControlFixtureCensus` refuses unless the three fixture policies
equal the first three landed control IDs in order and declare only the two
closed commands.

Observation 10. Nothing added here reads a provider, revision, or result fact
out of `controls/*/input.json`. The witness rows' `input.json` retains only the
fixture's claim, the interception label, the parent's witness transcript, the
reduced disposition, the seam kind, and any failure string.

## Review attack surface

Copied from the sub-slice 3.3 definition: a fixture's own claim accepted as
refusal evidence; a control that leaves the witness locked into the case phase;
a second holder-death attempt hidden in a control; a synthetic addon reaching a
path a real run would treat as native evidence; the death case repeated to find
a favourable result.

Review should additionally attack: the `boundary.spawn`, `boundary.seam`,
`boundary.fixtures` and `boundary.gates` substitution points, and whether the
`substitutions` observation member is a sufficient disclosure of them; the
`seamKind` brand, and whether any caller-reachable path can stamp a synthetic
row `WITNESS_CALL_INTERCEPTION`; the choice to leave a hung fixture child
running rather than signal it, and whether the open-resource ledger plus the
case-phase gate is a sufficient consequence; the decision that a refused reset
sets `witnessHeld` even when the witness never acquired; the fixture children
loading the stable witness rather than a candidate, and whether that is still a
faithful stand-in for the three ledger rows; the watchdog, which is not
unreffed so that a hung exchange must reach it; the addition of a
`substitutions` and a `witnessDisposition` member to every retained
observation, including the nine captured-input rows; whether
`enterNativeLockCasePhase` is the only path a later slice can take into the
case phase; and the `@ts-expect-error` suppressions in the new test, which are
the only way to import a landed experiment `.mjs` from a `.test.ts` inside this
footprint.
